# Bootstrap w/ Webpack

> [!IMPORTANT]
> This is a preview of [Bootstrap v6](https://github.com/twbs/bootstrap/tree/v6-dev), which is still in early alpha development. Expect frequent, breaking changes. For the stable Bootstrap 5 version of this example, see the [`main` branch](https://github.com/twbs/examples/tree/main/webpack).

Include [Bootstrap](https://getbootstrap.com)'s source Sass and individual JavaScript plugins with [Webpack](https://webpack.js.org).

## Edit in browser

[![Open in StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/twbs/examples/tree/v6-dev/webpack?file=src%2Findex.html)

## How to use

```sh
git clone https://github.com/twbs/examples.git
cd examples/webpack/
git checkout v6-dev
npm install
npm start
```
