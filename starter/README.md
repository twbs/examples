# Bootstrap starter

> [!IMPORTANT]
> This is a preview of [Bootstrap v6](https://github.com/twbs/bootstrap/tree/v6-dev), which is still in early alpha development. Expect frequent, breaking changes. For the stable Bootstrap 5 version of this example, see the [`main` branch](https://github.com/twbs/examples/tree/main/starter).
>
> Bootstrap v6 alpha isn't published to npm/jsDelivr yet, so this example's CDN links point at the `v6-dev` branch's built CSS/JS instead of a versioned release. Once an alpha ships, these will switch back to normal, SRI-hashed CDN links.

Include [Bootstrap](https://getbootstrap.com) CSS and JS via the [jsDelivr CDN](https://www.jsdelivr.com/package/npm/bootstrap).
